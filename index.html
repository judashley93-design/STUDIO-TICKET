Un accès sécurisé, téléphone par téléphone

Les applis ne s'ouvrent pas avec un mot de passe partagé : chaque appareil reçoit son propre code d'activation, qui ne fonctionne que sur lui.

Ouvrez le lien

Au premier lancement, l'appli affiche la référence unique de votre appareil.

Envoyez la référence

Touchez « Copier » ou « Partager » et envoyez-la à l'organisateur (message, WhatsApp...).

Recevez votre code

L'organisateur génère un code d'activation pour votre appareil et vous le renvoie.

Activez

Saisissez le code : l'appli s'ouvre, et ne vous le redemandera plus sur cet appareil.

Le code est lié à l'appareil : transmis à quelqu'un d'autre, il ne sert à rien. Si les données du navigateur sont effacées, un nouveau code est nécessaire.

Mode d'utilisation

De la création du billet au contrôle à l'entrée.

Créez avec le Studio

Choisissez un format, un fond, vos textes et vos images. Le Studio génère les billets numérotés avec leur QR code signé.

Imprimez

Exportez en PDF A4 ou A3 avec repères de coupe, en un seul fichier ou en plusieurs.

Réglez le Contrôle

Sur chaque téléphone : saisissez la clé secrète du Studio, donnez un nom au téléphone (Entrée A...), activez la synchronisation si besoin.

Scannez

Vert : entrée autorisée. Orange : déjà utilisé, avec l'heure et l'entrée. Rouge : faux ou illisible.

Installer l'appli

Une seule fois par appareil. Ensuite, elle s'ouvre depuis son icône.

Android

Ouvrez le lien dans Chrome, touchez « Installer l'appli » (ou menu ⋮ puis « Installer l'application »), puis ouvrez-la et activez-la.

iPhone

Ouvrez le lien dans Safari, bouton Partager puis « Sur l'écran d'accueil ». Ouvrez ensuite l'appli depuis l'icône et activez-la là : l'activation se fait dans l'appli installée.

Ordinateur

Dans Chrome ou Edge, cliquez sur l'icône d'installation de la barre d'adresse, puis activez l'appli.

Questions fréquentes

Faut-il internet pour utiliser les applis ?

Non. Internet sert à les installer, à recevoir les mises à jour et, si vous l'activez, à synchroniser plusieurs téléphones. Le contrôle et la création fonctionnent sans réseau.

Pourquoi un code par appareil ?

Pour que l'accès ne puisse pas circuler : un code d'activation ne fonctionne que sur l'appareil pour lequel il a été généré. Il n'existe pas de mot de passe commun à communiquer.

Puis-je utiliser l'appli sur un autre téléphone ?

Oui, mais cet autre téléphone doit être activé à son tour : il affiche sa propre référence, et l'organisateur lui génère son code.

J'ai changé de téléphone ou effacé les données de mon navigateur.

Rouvrez l'appli : elle affichera une nouvelle référence. Envoyez-la à l'organisateur pour recevoir un nouveau code.

Où sont enregistrées les données ?

Sur l'appareil. Pour le Contrôle, si la synchronisation est activée, les passages (code du billet, heure, nom du téléphone) sont aussi envoyés à la base de l'organisateur.

Le billet est refusé alors qu'il semble bon.

Vérifiez que la clé secrète saisie dans les Réglages du Contrôle est exactement celle du Studio, et que le QR code est net et entier.
